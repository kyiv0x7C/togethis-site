# Togethis — official website

Togethis is a Ukrainian-made iOS app of conversation question cards for couples,
families and friends: a free starter deck, paid decks as one-time purchases with
no subscription, no ads and no accounts, in Ukrainian and English.

Togethis — український iOS-застосунок з картками-питаннями для розмов пар,
сім'ї та друзів: безкоштовна стартова колода, платні колоди разовою покупкою
без підписки, без реклами й акаунтів, українська та англійська мови.
